# tools/schema

Reads the NNet type table out of a 4.10 client image and uses it to generate and check the
protocol code. Python 3, no packages. The client image is an input and is never copied into
the repository. How the table is laid out, and how it was worked out, is in
[docs/game-events.md](../../docs/game-events.md).

Set `KITSUNE_SC2_IMAGE` to `SC2_x64` (Linux) or `SC2_x64.exe` (Windows). Either one works; the
table is the same in both.

| Script | What it does |
|---|---|
| `gen_cpp.py` | Writes all the generated protocol C++: `Enums.h`, `Records.h`, `SystemEvent.h`, `LocalEvent.h`, and `GameEvent.h` in `include/Kitsune/Net/`, and `RecordCodec.h`, `Records.cpp`, `SystemEvent.cpp`, `LocalEvent.cpp`, and `GameEvent.cpp` in `src/Net/`. Run clang-format on them afterwards (the command is in `docs/game-events.md`, "Regenerating"). |
| `make_fixtures.py` | Writes `tests/fixtures/game_event_vectors.h`, `net_event_vectors.h`, and, with `KITSUNE_CAPTURE` set to a base-port pcap, `game_event_capture.h` (the committed one is from two house bots on AutomatonLE, whose guest turns are 21, 25, 27, 29; another pcap has other turn numbers and the script stops). Seeded, so a re-run is identical. |
| `catalog.py` | Prints the event ids (`ids`) or every event's field layout (`layouts`), as quoted in the docs. |
| `refcodec.py` | The reference encoder and random values for any type. Run it to check the encoder against the decoder, and against s2protocol when `S2PROTOCOL` names a directory holding the `s2protocol` package. |

Library modules: `image.py` finds and splits the table, `schema.py` parses the type definitions,
`gameschema.py` adds names and a decoder, `events.py` is the System, Local, and Game event tables, `pcap.py` reads
captures.

After a change to any of these, regenerate and confirm the generated files change only as you meant them to. The generated files carry a "Generated by" line; edit the tool, not them.
